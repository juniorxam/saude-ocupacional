# Meu Projeto

Sistema Flask de gestão de equipe e documentos.

## Execução

1. Crie um ambiente virtual: `python3 -m venv venv`
2. Ative-o e instale: `pip install -r requirements.txt`
3. Copie `.env.example` para `.env` e ajuste `DATABASE_URL`.
4. Execute: `python run.py`

O projeto foi reorganizado a partir dos arquivos exportados da conversa do DeepSeek.
